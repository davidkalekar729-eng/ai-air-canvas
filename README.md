# 🎨 AI Air Canvas (Virtual Drawing Pad)

A computer vision application that allows users to draw on a digital canvas using real-time hand gestures tracked through a webcam.

## 🚀 Features
- **Touchless Drawing:** Draw on screen using your index finger.
- **Color Selection:** Switch between colors (Blue, Green, Red, Yellow) via top-bar virtual UI buttons.
- **Canvas Controls:** Clear screen instantly by hovering over the "CLEAR ALL" button.
- **Real-Time Hand Tracking:** Powered by MediaPipe Hands and OpenCV.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** OpenCV, MediaPipe, NumPy
